# Maluzinha – Controle do Ateliê

App web para o ateliê **Maluzinha Laços e Encantos** (Fortaleza – CE) controlar o estoque de materiais, a lista de compras, os produtos de pronta-entrega e as encomendas.

Projeto desenvolvido para o Projeto de Extensão II do curso de Análise e Desenvolvimento de Sistemas (Programa de Ação e Difusão Cultural).

## Funcionalidades

- **Materiais:** cadastro de fitas, apliques, bico de pato, bases de tiara, elásticos e embalagens, com cor, quantidade, unidade e quantidade mínima
- **Compras:** lista automática do que está abaixo do mínimo, com envio pelo WhatsApp e registro das compras
- **Produtos:** peças de pronta-entrega com preço e quantidade
- **Encomendas:** cliente, produto, cor, prazo, status e pagamento, com atalho para o WhatsApp da cliente
- **Backup:** cópia de segurança em arquivo e exportação para planilha

Os dados ficam salvos apenas no navegador do aparelho (localStorage). Nenhuma informação de cliente é enviada para a internet.

## Tecnologias

HTML, CSS e JavaScript puro, publicado no GitHub Pages. Pode ser instalado no celular pelo "Adicionar à tela inicial".
